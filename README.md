# 🎼 Marked — The Digital Music Stand

Marked is a touch-friendly, real-time rehearsal platform designed for modern music ensembles. It allows directors to manage repertoire, push real-time bowings and annotations to their musicians, and provides individual practice tools—all from a browser.

## ✨ Key Features

* **Live Sync Annotations:** Built with Supabase Realtime, when a director draws a bowing, caesura, or dynamic marking, it instantly appears on every musician's device.
* **Smart Layers & Role-Based Workflows:** Directors have global edit rights, section leaders can push notes to their sections, and individuals can create private, personal markings.
* **Offline-Ready:** School Wi-Fi down? No problem. Scores are cached locally for instant, zero-lag opening even without an internet connection.
* **Practice Room Tools:** Features a high-precision visual/audio **Metronome** and a real-time microphone **Chromatic Tuner** built directly into the app.

## 🛠️ Tech Stack

* **Frontend:** React, TypeScript, Vite, Tailwind CSS
* **Backend:** Supabase (PostgreSQL, Auth, Storage, Realtime)
* **Local Caching:** LocalForage
* **Audio Processing:** Native Web Audio API
